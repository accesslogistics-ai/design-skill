# Access Design

Marketplace corporativo da Access Global Logistics para distribuição do plugin `access-design` no ChatGPT Workspace.

O plugin reúne logos oficiais, fontes essenciais, diretrizes de identidade, gerador de avisos e uma base visual para sistemas internos.

## Importação no workspace

1. No ChatGPT, acesse **Admin > Plugins**.
2. Selecione **Add > Import marketplace**.
3. Informe a URL deste repositório.
4. Mantenha o campo **Path** vazio e use a branch principal.
5. Após a importação, abra o plugin **Access Design** e defina a política de instalação para os perfis desejados.

O catálogo está em `.agents/plugins/marketplace.json` e o plugin em `plugins/access-design`.
